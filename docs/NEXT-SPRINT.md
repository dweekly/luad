# Release documentation contract

Update the public README and static website to describe the published experimental
0.2.0 release and its actual limitations.

Scope: `README.md`, `site/index.html`, and this checkpoint. Use the published 0.2.0
release, its accepted revision, and the README's current coverage table as authority.
Correct version metadata, download instructions, and stale defect descriptions.

Evidence: parse HTML and structured metadata; check release links and local assets;
execute the documented download, checksum, provenance, and version commands; require
CI and the Pages deployment to pass; compare deployed HTML with the accepted source.

Stop after the corrected site is live. No feature work, support promotion, release
asset changes, or version-tag movement is authorized.
